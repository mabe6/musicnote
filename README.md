Dot — size in pixels of the red dots drawn on the overlay grid

Note→note (ms) — how long to wait between clicking each note button in game, also used before clicking the delay block

Base→delay (ms) — base wait time after clicking a delay block, gives the game server time to register all note connections

+ms/note — extra wait added per note in that tick on top of the base delay (more notes = more server load = longer wait needed)

Tempo wait (s) — how long to wait after switching to the delay tool (slot 6) before starting to click delay blocks

Wiggle px — radius in pixels of the circular mouse movement done before each click (needed for roblox to detect the mouse)

Wiggle cnt — how many steps the circular wiggle makes (more = smoother circle)

Skew X / Skew Y — fine-tunes the overlay grid alignment horizontally/vertically if the dots don't line up perfectly with the in-game grid

Tempo round Down/Up — when a delay value doesn't fit exactly into the game's 0.01s steps, round it down (slightly faster) or up (slightly longer)

Cols / Rows — manually override how many columns/rows the delay grid

Capture Tempo UI — records where the delay value input box is on screen so the macro can type values into it

Minimize on play — hides the macro window when playback starts so it's not in the way
